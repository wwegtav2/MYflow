1. Home Screen

Clock Widget: * Test clicking on the time display; the system should open a full-screen/enlarged clock view.

Test clicking the screen again; it should close the clock view and return to the normal home screen.

Weather Widget: * Verify that the widget correctly fetches and displays today's temperature and weather conditions.

2. Finance

Category Management: Test the "Create New Category" functionality to ensure a new category is successfully added.

Transaction Logging: Test the "Add Income" and "Add Expense" buttons by submitting mock data.

Calculation & Dashboard: After adding transactions, verify that the system correctly calculates and updates the displays for "Today's Income", "Today's Expense", and "Total Balance" (Net Total).

3. Study (Learning Tracker)

Study Timer: * Test starting the timer by selecting a specific subject, and then try starting it without selecting any subject.

Verify the timer runs and continuously updates the UI.

Test the Stop/Exit button to ensure it correctly halts the timer and saves the session.

Progress Tracking: * Test adding a "Main Topic" (e.g., "Java").

Test adding "Sub-topics" under the newly created Main Topic.

Test checking/ticking the checkbox of a sub-topic; verify that the system successfully records this action and updates the overall learning progress.

4. Calendar

Create Event: Test adding a new event by providing an event type (icon), event name, date, time, and quick-start option. Test saving the event both with and without optional notes.

Calendar View Rendering: Verify that the created event accurately appears as a small dot/indicator on the corresponding date in the calendar grid.

View Details & Delete: Test clicking the event indicator on the calendar to reveal its details. Test clicking the "Delete" button and verify the event is completely removed from the calendar.

5. Settings

Theme Toggle: Test switching between Light Mode and Dark Mode; verify the UI colors update accordingly.

UI Customization: * Test applying a new background color.

Test changing the application font.

Test modifying the clock's background style/type.

Wallpaper Settings: Test updating the application wallpaper using two different methods: 1) Uploading an image file, and 2) Providing a direct image URL.
